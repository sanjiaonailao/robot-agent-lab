\# Robot Agent Lab



Language-Guided Robotic Manipulation with LLM Planning and Closed-Loop Feedback.



\## Project Overview



This project explores how Large Language Models (LLMs) can be used to plan and execute robotic manipulation tasks in simulated environments.



The project is built around ManiSkill, with a focus on robotic task planning, execution monitoring, and failure recovery.



\## Objectives



\- Set up a robotic manipulation simulation environment.

\- Implement basic robotic manipulation skills.

\- Integrate LLM-based task planning.

\- Develop a closed-loop execution and failure recovery system.

\- Evaluate task success rates and planning performance.
